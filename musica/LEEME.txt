JAVA RADIO · 140.1 · carpeta de música local
===========================================

Suelta aquí tus archivos de audio (mp3, m4a, wav, flac, ogg…).
El servidor los lee al arrancar y cada 5 minutos, o cuando pulsas
«Actualizar» en la web.

Cómo se leen los nombres
------------------------
  Artista - Título.mp3          →  Artista / Título
  01 - Artista - Título.mp3     →  Artista / Título
  Título.mp3                    →  Lott Campuzano / Título
  Tema [electronica].mp3        →  género manual entre corchetes

Portadas
--------
Pon una imagen con el mismo nombre que el audio:

  Lott Campuzano - Medianoche en la cabina.mp3
  Lott Campuzano - Medianoche en la cabina.jpg

También vale cover.jpg, portada.jpg, front.jpg, folder.jpg o album.jpg
en la misma carpeta.

Subcarpetas
-----------
Puedes organizar por álbumes o sesiones. El nombre de la subcarpeta
aparece como álbum en la web.

Clasificación
-------------
Java Radio lee etiquetas ID3/Vorbis/RIFF (género, ánimo y BPM).
Si un archivo no tiene etiquetas, usa el sufijo [genero] del nombre
o asigna un perfil estimado para que la recomendación por hora
siga funcionando.

Prueba rápida
-------------
  npm run demo-audio

Genera cuatro temas instrumentales de prueba para que la radio
suene desde el primer minuto. Puedes borrarlos cuando quieras.

Nota: esta carpeta es el modo local. Para usar Google Drive, mira
el README y el archivo .env.example.
